# ProteinMisfolding

## Overview
###### ProteinMisfolding is a software that models protein misfolding, specifically amyloid-β. Misfolded proteins often 'form large polymers of unwanted aggregates' (Ashraf et al., 2014); this occurrence is prevalent in neurodegenerative diseases such as Alzheimer's disease (AD). Amyloid deposits are formed when an α-helix transforms into a β-helix; AD is 'characterised by the accumulation of amyloid-β in the brain' (Ashraf et al., 2014).
